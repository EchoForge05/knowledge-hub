# 输入暂存区

可直接在 Codex 对话中提供零散记录，不要求先创建输入文件。

建议同时说明可公开范围、适用版本、来源链接和不确定之处；不知道的项可留空并说明。Agent 会先检索已有主题，再选择新建、更新或无需改动。处理顺序和来源记录见[知识整理流程](../docs/handbook/knowledge-workflow.md)。

如果需要本地暂存，将原文放入本目录下的 `local/` 子目录；根 `.gitignore` 已忽略该路径，当前没有创建或收集任何原始记录。需要入库的可公开来源摘要由 Agent 随知识文档保存，不能依赖本地临时文件实现跨设备追溯。

不要把银行内部文档、客户信息、密钥或未经授权的数据写入仓库。忽略规则不提供加密，也不会清除已跟踪的文件。未来 Issues 是否作为持久来源，需先确认可见性和权限。

# 网站与本地统一阅读历史提案

本页保留当时的需求与备选方案。实现及验收见[离线阅读记录](offline-reading.md)，操作见[离线阅读用法](../../handbook/usage.md#离线阅读)。

日期：2026-11-01。需求已确认：分散的文件不能作为日常阅读入口，本地与网站都需方便阅读。以下实现方案为提案，待用户确认；尚未开发或验收。

后续澄清：用户要求“本地也有一份完整的可以随时查看的”。本地完整副本、独立于网站与Codex、准备后断网可读为已确认需求。此前以Node与本机服务作为日常阅读前提的建议不再作为首选；以下相关描述仅保留方案演变，当前方向以本节为准。

## 当前推荐：可直接打开的离线知识库

生成独立的本地阅读交付物，包含全部已入库知识正文、图片、样式、分类目录、文章内跳转和离线搜索。日常通过单一入口打开，不要求读者安装Node、运行命令、启动开发服务或保持Codex运行；外部来源网页不在完整副本范围，保留链接并明确联网要求。

优先验证可直接在浏览器打开的离线HTML阅读文件：内部按分类与文章组织，保留完整知识讲解，不能仅把分散文件拼成长文。将需要的资源内嵌或随包保存，搜索与跳转需在真实file协议、断网环境验证，不能假定现有VitePress构建产物可直接使用。具体单文件或目录包形式仍属技术设计，验证前不承诺已可用；若无法满足，再评估其他打包方式并说明取舍。

构建时继续复用同一批Markdown，网站和本地副本不分别编辑。生成物包含内容版本、文章数量与生成时间；更新时生成新副本，失败保留旧副本。不自动联网、下载运行环境或启用同步。完整性指全部已入库知识和本地阅读必需资源，不包括未整理输入、私有草稿、外部网站全文或项目执行日志。

实施验收必须增加：在未启动任何本项目服务、关闭Codex且断开外网的情况下直接打开交付物，逐篇核对现有7篇知识完整性、代码/表格/图片、中文与标识符搜索、文章和段落跳转；移动交付物到含空格的新目录后复验。尚未实施，不将本条当成通过记录。

## 使用模式

采用“一份内容、两个阅读入口”：Markdown 继续作为维护与版本管理的源文件，公开网站和本地阅读器呈现相同的分类目录、文章、全文搜索与段落跳转。本地用户从一个入口进入知识库，不必逐个寻找或打开文件。

本地阅读器第一版建议复用现有站点界面与生产构建，在本机浏览器打开；提供 Windows 双击启动入口。它不是浏览远程网站的快捷方式，文章、图片、样式和搜索索引均来自本地。首次准备完成后，断网也能阅读，来源外链仍需联网。

## 阅读流程

| 场景 | 预期体验 |
| --- | --- |
| 网站阅读 | 打开既有网址，通过分类、目录、搜索进入文章 |
| 本地阅读 | 双击统一启动入口，自动打开本机知识首页，无需手工输入命令或地址 |
| 查找知识 | 与网站复用分类、全文搜索、文章目录、上一篇/下一篇及内链 |
| 断网阅读 | 已准备的本地正文、图片、代码展示、搜索和跳转均可用 |
| 查看版本 | 本地显示内容版本和构建时间，能判断是否落后于已发布版本 |
| 更新阅读内容 | 显式更新本地阅读版本；失败保留上一份可用内容，不在启动时强制联网 |

这里的“一致”是同一内容版本下正文与阅读能力一致。未发布的本地修改和已发布网站允许版本不同，需明确显示，不能承诺两端实时同步。

## 内容与运行边界

继续按主题维护 knowledge/，不合并成一篇巨大的 Markdown，不分别维护线上与本地正文。网站和本地均由同一份源文件生成；项目执行过程仍留在 docs/，不混入知识正文。

第一版将现有 Node 环境作为本地运行前提，启动器检查环境并给出可操作提示，不静默下载软件或修改系统配置。日常阅读使用已构建内容；内容维护、检查与更新是独立操作，不要求每次阅读重新安装依赖或构建。

本机服务只监听回环地址，仅提供阅读产物，不暴露仓库、输入或私有目录。处理端口占用、重复启动、路径含空格、缺失/损坏产物和停止服务等情况；退出浏览器与停止本机服务的关系必须在入口中说明。启动器不依赖 Codex 缓存中的机器专属路径。

运行模式与具体打包方式在实施时验证；现阶段不宣称现有构建产物已通过离线阅读验收。直接双击构建 HTML 的方式不列为交付承诺。

## 第一版范围与后续选择

第一版建议交付 Windows 本地启动入口、独立的阅读产物准备/更新命令、版本提示、启动/停止说明，以及本地与网站同版本内容检查。保留现有网站和知识编辑流程，不新增模型调用、账号、后台自动同步或开机自启。

尚需确认：是否接受首次准备 Node 环境。如果要求在没有 Node 的电脑上解压即可阅读，需要另外设计自带运行环境的便携包，评估体积、运行环境分发与跨机器验证；不把它冒充为首版已支持。PDF/Word 可另作导出选项，不能替代带搜索和内链的统一入口。

## 验收与推进

1. 在含空格的 Windows 路径双击启动，自动打开正确首页；重复启动、端口占用与缺少环境时有明确结果。
2. 断开外网后逐页阅读现有知识，验证分类、搜索实际跳转、图片、代码、目录与文章内链；来源外链明确保留在线属性。
3. 核对本地阅读版本与对应网站构建的文章集合及正文；本地修改未发布时，版本提示不能造成误解。
4. 更新成功切换到新版本；准备失败保留旧版本，重新启动仍可阅读；明确服务停止与重启行为。
5. 执行适用文档检查、构建、产物检查及浏览器验证，补齐使用教程；未验证的平台不声明支持。

用户确认方案后再确定实施拆分与 Git 分支，先完成本地准备、启动、阅读闭环，再做更新失败恢复与完整验收。远程推送、合并、部署仍遵循当次授权，不沿用旧批次权限。

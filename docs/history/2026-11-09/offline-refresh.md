# 离线副本自动刷新验证

按 D057 将离线构建加入 Codex 知识维护收尾，并加上可选的保存监听命令。两条路径复用同一生成器，写入固定的 `dist/offline/Knowledge Hub.html`。

在本机 Windows 和 Node 24.22.1 实测监听启动时生成、添加文章后自动生成、无效链接导致构建失败且旧 HTML 哈希保持一致、修正后自动恢复、删除临时文章后从副本移除。测试结束后停止监听，清理临时文件，重新生成 17 篇正式文章的离线 HTML，内容版本 `b448ef7ad120`。文档检查、站点构建、产物引用检查及 `git diff --check` 通过。未重新执行浏览器交互或其他平台的监听测试。

当前分支 `fix/offline-content-version`，本批与已有修改均留在工作区。下一步可打开当前 HTML 审阅，手动编辑时可按[离线阅读说明](../../handbook/usage.md#自己编辑时保存后自动更新)启用监听。

# Git 差异检查：工作区与暂存区

适用环境：Git 2.55.0 手册中的基本比较模式；核查日期：2026-10-31。下列为只读检查示例，未对这些示例逐项运行验收。

## 三种比较

| 命令 | 比较范围 |
| --- | --- |
| `git diff` | 工作区相对于暂存区的改动 |
| `git diff --cached` | 暂存区相对于 HEAD 的改动；尚无 HEAD 时显示已暂存内容 |
| `git diff HEAD` | 工作区相对于 HEAD 的改动，覆盖已暂存和未暂存部分 |

这些模式用于比较被跟踪的内容；新文件是否被 Git 发现，还应通过状态检查确认。

## 限定范围

使用 `--` 分隔选项与文件路径，减少路径被当成其他参数的歧义。

```sh
git diff -- knowledge/
git diff --cached -- knowledge/
```

检查差异不会创建提交。提交前需要同时确认暂存文件范围和实际差异。

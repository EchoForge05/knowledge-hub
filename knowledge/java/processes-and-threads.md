# 进程、线程与 Java 并发

## 什么是进程和线程？它们有什么区别？

进程是操作系统进行资源分配和管理的基本单位，线程是 CPU 调度和执行的基本单位。一个进程可以包含多个线程，同一进程中的线程共享进程的内存资源，但各自拥有独立的线程栈等运行资源。进程之间的资源隔离通常更强，线程之间通信更方便，但共享数据时需要考虑线程安全问题。Java 中，一个 JVM 进程可以包含多个业务线程、GC 线程等。

## 共享与隔离的边界

进程通常拥有独立地址空间，也可通过显式共享内存等机制通信；线程共享进程资源，各自维护调用栈与执行状态。共享数据方便协作，也带来竞态与可见性问题。上述“CPU 调度单位”是传统平台线程模型的概括，不表示所有 Java 线程都与操作系统线程一一对应。JVM 内线程的种类和数量取决于实现与配置。

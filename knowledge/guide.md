# 使用指南

## 浏览与搜索

从[知识目录](topics.md)选择主题。电脑上使用顶部搜索按钮或快捷键 Ctrl / Command + K；手机上点击搜索图标，点击“目录”展开侧栏。

搜索支持中文词语、英文术语和代码标识符。使用关键词组合缩小范围；没有结果时可尝试较短的词语。点击结果可打开对应页面和段落。

## 阅读

正文旁的“本页目录”用于定位小节。手机阅读长代码或宽表格时，在内容区域横向滑动；顶部可切换浅色和深色外观。

## 增补知识

将记录交给维护 Agent，说明来源、适用版本和哪些内容不确定。维护时先查找已有主题，再决定更新或新建；重复输入应避免重复文章。

内容经整理与 PR 审核后发布，网站没有在线编辑入口。

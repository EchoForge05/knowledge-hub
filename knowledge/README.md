# 知识正文目录

这里预留未来网站正文，目前没有正式知识文章，也没有站点配置。

| 目录 | 范围 |
| --- | --- |
| `java/` | Java 语言、JVM、并发等 |
| `spring/` | Spring 及其生态 |
| `databases/` | 数据库原理、产品实践、SQL |
| `linux/` | Linux 与日常运维 |
| `git/` | Git 与协作 |
| `ai-agent/` | AI Agent 及工具实践 |
| `software-engineering/` | 软件设计、开发、测试与交付 |
| `banking/` | 可公开或获准脱敏的银行核心业务知识 |
| `assets/images/` | 知识图片 |

目录只是初始归档位置，不是固定分类模型。先搜索已有主题，优先更新文章；随着实际内容增长再增加层级和关联。不要为了填满目录生成示例事实。

维护方法见 [知识整理流程](../docs/handbook/knowledge-workflow.md)和 [Markdown 规范](../docs/handbook/markdown.md)。
